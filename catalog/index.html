How an install stays pinned

Repository
Trust covers the whole repository. Adding it is one owner command; removing it stops new installs and leaves deployed apps alone.
Tag
Each release is a tag named after the app, like pastebin/v0.1.0, so apps in one repository version independently.
Fingerprint
The h1 is a SHA-256 over every file the app deploys, computed the way Go’s go.sum does. If a tag is moved to different files, the fingerprint no longer matches and the install is refused. The seal beside each app is drawn from its fingerprint.
Index
index.json lists every app folder with its version, tag and fingerprint. A check on every push fails if any of them is out of date.
